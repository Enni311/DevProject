# DevProject — Next-Gen Web Experience

Навчальний вебпроєкт із сучасним, високоінтерактивним UI/UX дизайном. Головна мета проєкту — відпрацювання навичок верстки, CSS-анімацій, створення Single Page Application (SPA) на чистому JavaScript та реалізація нестандартної навігації.


## Технологічний стек

- HTML5: Семантична розмітка, використання SVG-елементів.
- CSS3: Flexbox, CSS Grid, CSS Variables, Glassmorphic styling, Keyframe анімації, 3D Transforms.
- Vanilla JavaScript (ES6+): 
  - Управління станом SPA без використання сторонніх фреймворків;
  - Обробка подій wheel та touchstart/touchend;
  - Логіка керування модальними вікнами та перемикання тем.

---

## Структура проєкту

├── index.html # Головний HTML-файл (структура SPA та всіх сторінок)
├── style.css # Стилі, CSS-змінні, анімації та адаптивність
└── app.js # Скрипт слайдера, обробка колесика миші та модалок
